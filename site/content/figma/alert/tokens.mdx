# Tokens

Standardized design system values that define consistent visual properties across alert components. These tokens ensure visual coherence while enabling flexible theme customization and brand adaptation for critical messaging and user confirmation interfaces.

## Theming Tokens

Design tokens organized by category with color-coded labels indicating their scope and impact level. Each token includes detailed specifications with values, usage guidelines, and customization options.
