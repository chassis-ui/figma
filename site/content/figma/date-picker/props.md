# Props

Configurable properties that control the appearance, behavior, and functionality of date picker components for temporal selection and calendar navigation management.

## Day Item Props

Properties that define the visual state and interactive behavior of individual date elements within calendar structures.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### state: variant

Controls the visual state and interactive feedback of the day element based on date context, user interaction, and selection status.

## Nav Item Props

Properties that define the visual state and navigation functionality of temporal movement elements within date picker interfaces.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the navigation functionality and presentation format of the navigation element based on temporal movement requirements.

#### state: variant

Controls the interactive state and visual feedback of the navigation element based on user interaction and availability status.

#### has-caret: boolean

Controls the visibility of dropdown indicator that signals available dropdown functionality for direct month or year selection within navigation components.

## Date Picker Props

Properties that define the visual state and interface configuration of complete date selection systems for comprehensive temporal interaction.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the date picker interface structure and selection capabilities based on temporal selection complexity and layout requirements.

#### has-time: boolean

Controls the visibility and inclusion of time selection functionality within the date picker interface for date-time input requirements.

#### has-presets: boolean

Controls the visibility and inclusion of preset date range shortcuts within the date picker interface for quick selection convenience.
