# Tokens

Standardized design system values that define consistent visual properties across mobile navigation bottom components. These tokens ensure visual coherence while enabling flexible theme customization and brand adaptation.

## Theming Tokens

Design tokens organized by category with color-coded labels indicating their scope and impact level. Each token includes detailed specifications with values, usage guidelines, and customization options.
