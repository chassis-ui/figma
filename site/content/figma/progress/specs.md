# Specs

Technical specifications and measurements for progress components that ensure consistent implementation and precise visual rendering across different platforms and interface contexts.

**Legend:**

- Brackets ([ ]) denote a component variant placeholder.
- Full emphasis indicates a value specific to that variant.
- Dimmed indicates a value unchanged from the default variant.

## Progress Bar Component

Linear progress indication elements that display task completion through visual fill representation with precise dimensional and spacing specifications for consistent progress visualization.

### Design Tokens

Standardized design values used in progress bar components. Includes specifications for step segmentation, fill progression, completion states, and visual feedback across all progress bar variants.

## Progress Step Component

Individual step milestone elements that display specific completion states within progress sequences with precise dimensional and spacing specifications for consistent step visualization.

### Design Tokens

Standardized design values used in progress step components. Includes specifications for step styling, state indicators, connection elements, and visual hierarchy across all progress step variants.

## Progress Flow Component

Complete progress tracking systems that combine multiple step elements with precise dimensional and spacing specifications for consistent overall progress visualization.

### Design Tokens

Standardized design values used in progress status components. Includes specifications for step arrangement, size variants, completion tracking, and overall layout consistency across all progress flow variants.

## Loading Indicator Component

Dynamic progress indication elements that display indeterminate loading states with precise dimensional and animation specifications for consistent loading feedback.

### Design Tokens

Standardized design values used in progress loader components. Includes specifications for loading animations, label positioning, dynamic states, and visual feedback across all loading indicator variants.
