# Specs

Technical specifications and design system values that define the visual and structural properties of button group components. These specifications ensure consistent implementation across design tools and development environments.

**Legend:**

- Brackets ([ ]) denote a component variant placeholder.
- Full emphasis indicates a value specific to that variant.
- Dimmed indicates a value unchanged from the default variant.

## Button Group Item Component

Specifications for individual button elements within grouped interfaces including measurements, colors, typography, and interactive styling attributes. These values define the visual presentation and interaction properties for button group item implementations.

### Design Tokens

Standardized design values used in button group item components. Includes specifications for each type, context, size, and state variant, with interaction feedback rules for consistent appearance and behavior across all button group item implementations.

## Button Group Component

Specifications for container elements that organize collections of related buttons including measurements, colors, layout styling, and grouping attributes. These values define the visual organization and coordination properties for button group implementations.

### Design Tokens

Standardized design values used in button group components. Includes specifications for each context and layout variant, with coordination styling rules for consistent appearance and behavior across all button group implementations.

## Cart Button Group Component

Specifications for specialized quantity control elements designed for e-commerce interactions including measurements, colors, typography, and e-commerce-specific styling attributes. These values define the visual presentation and functional properties for cart button group implementations.

### Design Tokens

Standardized design values used in cart button group components. Includes specifications for each layout and size variant, with e-commerce interaction rules for consistent appearance and behavior across all cart button group implementations.
