# Props

Configurable properties that control the appearance, behavior, and functionality of button group components for action organization and coordinated interface interactions.

## Button Group Item Props

Properties that define the visual state and interactive behavior of individual button elements within grouped interface structures.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### context: variant

Controls the visual style and semantic meaning of the button group item based on its intended purpose and importance within the group hierarchy.

#### size: variant

Controls the dimensional scale and proportional relationships of the button group item component to optimize usability across different interface contexts.

#### state: variant

Controls the interactive state and visual feedback of the button group item based on user interaction and availability within the group structure.

#### has-icon-start: boolean

Controls the visibility of an icon element positioned before the button group item label for enhanced visual identification and action context.

#### icon-start-instance: instance-swap

Specifies which icon component to display when the has-icon-start property is enabled, providing visual identification within the group item.

#### has-badge: boolean

Controls the visibility of a badge element positioned after the button group item label for displaying counts, notifications, or status indicators.

#### is-dropdown: boolean

Controls the visibility of a dropdown indicator that signals additional actions or options available from the button group item.

#### has-icon-end: boolean

Controls the visibility of an icon element positioned after the button group item label for supplementary visual information and action context.

#### icon-end-instance: instance-swap

Specifies which icon component to display when the has-icon-end property is enabled, providing additional visual context within the group item.

## Button Group Props

Properties that define the visual state and layout organization of container elements that present collections of related buttons through unified treatment.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### context: variant

Controls the visual style and semantic meaning of the button group based on its intended purpose and importance within the interface hierarchy.

#### layout: variant

Controls the spatial arrangement and orientation of button elements within the group structure, determining horizontal or vertical organization patterns.

## Cart Button Group Props

Properties that define the visual state and functional behavior of specialized quantity control elements designed for e-commerce product management interactions.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### layout: variant

Controls the spatial arrangement and orientation of quantity control elements within the cart button group structure for optimal space utilization.

#### size: variant

Controls the dimensional scale and proportional relationships of the cart button group component to optimize usability across different shopping interface contexts.
