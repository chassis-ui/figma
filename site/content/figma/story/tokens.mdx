# Tokens

Standardized design system values that define consistent visual properties across story components. These tokens ensure visual coherence while enabling flexible theme customization and brand adaptation for full-screen narrative and content browsing interfaces.

## Theming Tokens

Design tokens organized by category with color-coded labels indicating their scope and impact level. Each token includes detailed specifications with values, usage guidelines, and customization options.
