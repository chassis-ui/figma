# Props

Configurable properties that control the appearance, behavior, and functionality of story components for content presentation and interactive story experiences.

## Story Button Props

Properties that define the visual state and interactive behavior of story button elements that provide access to story content through compact presentation formats.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the visual presentation format and content display approach of the story button, determining whether avatar-based or icon-based presentation is used for story identification.

#### state: variant

Controls the viewing status and visual emphasis of the story button based on user interaction history, determining whether unread or read styling is applied.

#### icon: instance-swap

Specifies which icon component to display when providing functional story identification and branded content representation within the story button.

## Story Card Props

Properties that define the visual state and content organization of story card elements that present story content within structured visual boundaries through expanded formats.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### state: variant

Controls the viewing status and visual emphasis of the story card based on user interaction history, determining whether unread or read styling is applied.

#### icon: instance-swap

Specifies which icon component to display when providing story identification and content representation within the expanded story card layout.

## Story Carousel Props

Properties that define the visual state and content organization of story carousel elements that present collections of story content through horizontal navigation patterns.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the story presentation format and layout approach within carousel contexts, determining whether circular button-based or rectangular card-based story display is used for collection browsing.
