# Specs

Technical specifications and design system values that define the visual and structural properties of floating button components. These specifications ensure consistent implementation across design tools and development environments with proper elevation and shadow styling.

**Legend:**

- Brackets ([ ]) denote a component variant placeholder.
- Full emphasis indicates a value specific to that variant.
- Dimmed indicates a value unchanged from the default variant.

## Floating Button Component

Specifications for elevated button elements including measurements, colors, typography, shadow properties, and elevation styling attributes. These values define the core appearance, elevation behavior, and Material Design FAB-equivalent properties for each floating button variant.

### Design Tokens

Standardized design values used in floating button components. Includes specifications for each variant, elevation levels, shadow properties, and state-dependent styling rules for consistent appearance and elevated behavior across all floating button implementations.
