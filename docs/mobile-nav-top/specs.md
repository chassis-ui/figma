# Specs

Technical specifications and design system values that define the visual and structural properties of mobile navigation top components. These specifications ensure consistent implementation across design tools and development environments.

**Legend:**

- Brackets ([ ]) denote a component variant placeholder.
- Full emphasis indicates a value specific to that variant.
- Dimmed indicates a value unchanged from the default variant.

## Top Navigation Component

Specifications for mobile navigation container elements including measurements, colors, typography, and platform-specific styling attributes. These values define the visual presentation and structural properties for mobile navigation implementations.

### Design Tokens

Standardized design values used in mobile navigation top components. Includes specifications for each type variant, platform-specific styling, and context-dependent presentation rules for consistent appearance and behavior across all mobile navigation implementations.
