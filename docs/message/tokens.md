# Tokens

Design tokens that control the visual appearance, spacing, and behavioral characteristics of message components, ensuring consistent conversational communication across different messaging contexts and maintaining design system coherence.

## Theming Tokens

Visual styling and appearance tokens that define the color, typography, and visual treatment of message components to maintain consistent messaging interfaces across different theme contexts and conversational requirements.

### Legend

- Granular tokens that affect only this component.
- Granular tokens that affect other components.
- Semantic tokens that affect the whole application.
- Base tokens that affect the whole application.
