# Props

Configurable properties that control the appearance, behavior, and functionality of chart components for data visualization and analytical presentation interfaces.

## Bar Chart Props

Properties that define the visual state and data presentation of bar chart elements that represent comparative data through rectangular visualization.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### has-y-markers: variant

Controls the visibility and styling of vertical axis markers that provide value reference points and grid structure for data comparison and interpretation.

#### Graph -> markers: variant

Controls the quantity and density of data markers within the nested graph component, determining how many marker points are displayed for data reference and grid structure.

#### X Axis -> markers: variant

Specifies the quantity and density of horizontal axis markers within the nested axis component, determining how many categorical or sequential reference points are displayed.

## Area Chart Props

Properties that define the visual state and data presentation of area chart elements that represent continuous data through filled trend visualization.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### trend: variant

Controls the overall direction and visual emphasis of the area chart trend line, determining the data progression presentation and analytical focus.

#### has-y-markers: variant

Controls the visibility and styling of vertical axis markers that provide value reference points and grid structure for data interpretation.

#### Graph -> type: variant

Specifies the visual presentation format of the nested graph component, determining whether linear or curved styling is applied for trend visualization.

#### Graph -> markers: variant

Controls the quantity and density of data point markers within the nested graph component, determining how many marker points are displayed for enhanced data point identification and reference.

#### Graph -> has-dots: boolean

Controls the visibility of individual data point indicators within the nested graph component for precise value identification and data point emphasis.

#### X Axis -> markers: variant

Specifies the quantity and density of horizontal axis markers within the nested axis component, determining how many temporal or categorical reference points are displayed.

## Gauge Chart Props

Properties that define the visual state and performance presentation of gauge chart elements that represent single metric values through circular indicators.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the structural shape and coverage of the gauge chart, determining whether circular, horseshoe, or semicircle presentation is used for metric display.

#### Graph -> weight: variant

Specifies the thickness and visual prominence of the gauge indicator within the nested graph component for metric emphasis and visual hierarchy.

## Donut Chart Props

Properties that define the visual state and compositional presentation of donut chart elements that represent proportional data through segmented circular visualization.

### Figma Component Props

Component properties specific to Figma design system implementation.

#### type: variant

Controls the layout arrangement and legend positioning of the donut chart, determining whether bottom legend or right legend spatial organization is used.

#### Graph -> slice: variant

Controls the number of data segments within the nested graph component, determining how many slices are displayed in the donut chart for data categorization.

#### Graph -> weight: variant

Specifies the thickness and visual prominence of the donut ring within the nested graph component for proportional emphasis and visual clarity.
