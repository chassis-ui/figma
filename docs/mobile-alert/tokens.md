# Tokens

Standardized design system values that define consistent visual properties across mobile alert components. These tokens ensure visual coherence while enabling flexible theme customization and brand adaptation for mobile-specific messaging and user confirmation interfaces.

## Theming Tokens

Design tokens organized by category with color-coded labels indicating their scope and impact level. Each token includes detailed specifications with values, usage guidelines, and customization options for comprehensive mobile alert styling and behavior control.

### Legend

- Granular tokens that affect only this component.
- Granular tokens that affect all mobile alert components.
- Semantic tokens that affect the whole application.
- Base tokens that affect the whole application.
