# Specs

Technical specifications and design system values that define the visual and structural properties of mobile alert components. These specifications ensure consistent implementation across design tools and development environments for mobile-specific messaging and user confirmation interfaces.

**Legend:**

- Brackets ([ ]) denote a component variant placeholder.
- Full emphasis indicates a value specific to that variant.
- Dimmed indicates a value unchanged from the default variant.

## Mobile Alert Window Component

Specifications for mobile-optimized modal dialog elements including measurements, colors, typography, and styling attributes. These values define the core appearance and behavior properties for each mobile alert window variant requiring immediate user attention and response within mobile applications.

### Design Tokens

Standardized design values used in mobile alert window components. Includes specifications for each variant and state-dependent styling rules for consistent appearance and behavior across all mobile alert window implementations.

## Mobile Alert Screen Component

Specifications for mobile-optimized full-screen overlay elements including measurements, colors, typography, and styling attributes. These values define the comprehensive appearance and behavior properties for each mobile alert screen variant with extensive messaging capabilities designed for mobile environments.

### Design Tokens

Standardized design values used in mobile alert screen components. Includes specifications for each variant and state-dependent styling rules for consistent appearance and behavior across all mobile alert screen implementations.
